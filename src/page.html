an instrument you draw with your finger

Three things to try

  1. Drag on empty space to stretch a new string. Longer makes it lower; crossing another string makes it an independent voice.
  2. Drag across a string to pluck it. Rub along it to bow, and hold still to mute.
  3. Drag a bright endpoint to retune that string while it rings.

Strings near each other shake the space between them, so a pluck spreads into the neighbours. What you hear is that wave: each string's length sets its pitch, and the shape you leave in it sets its timbre.

How it works

Every line you draw becomes a real wave simulation: a thread pinned at both ends, integrated a few dozen times per second. Touching it displaces the thread; the wave then runs out to the pinned ends, reflects, and interferes with itself. That interference is what your ear hears as a pitch.

Length sets pitch. Halve a string's length and the pitch goes up an octave — the readout shows the number so you can hear it happen.

Shape sets timbre. A sharp triangular pluck contains many overtones and sounds bright. Rubbing along a string pushes it gently toward a single smooth curve, which sounds pure and sustained.

Proximity sets harmony. Strings close together push on each other, so nearby strings drift in and out of phase. Crossing a string while drawing makes the new one ignore that coupling, which is how you get two independent voices instead of one blurred chord.
